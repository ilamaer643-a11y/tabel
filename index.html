Как получить конфиг (один раз):
  1. Зайди на firebase.google.com, войди своим Google.
  2. «Добавить проект» → имя любое → аналитику выключи → создать.
  3. Слева Build → Realtime Database → Создать базу → регион Europe.
  4. Вкладка Rules → вставь {"rules":{".read":true,".write":true}} → Опубликовать.
  5. ⚙ шестерёнка → Настройки проекта → вниз «Ваши приложения» → значок </> (веб) → зарегистрировать → хостинг НЕ надо.
  6. Скопируй блок firebaseConfig = { … } целиком (все фигурные скобки).
Конфиг хранится только на этом телефоне. На втором телефоне вставь тот же конфиг — табель подтянется сам.
